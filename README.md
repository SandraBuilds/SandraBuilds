👋 Hey, I’m Sandra!<br/>

“I believe code is more than syntax — it’s the bridge between imagination and intelligence.”<br/>

From the moment I discovered artificial intelligence, I knew I’d found my calling. What started as curiosity — experimenting with how machines can think, learn, and solve problems — evolved into a lifelong mission to merge AI, data, and software engineering to build products that make life smarter, simpler, and more connected. I’m deeply fascinated by how data fuels intelligence, how algorithms shape decisions, and how code can turn ideas into living systems. My journey is driven by the belief that with the right tools and vision, technology can completely redefine industries, especially across Africa.<br/>

💻 Software Engineer & Founder in the making — building products that merge innovation, intelligence, and real-world impact.
